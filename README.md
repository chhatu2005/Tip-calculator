# 💰 Tip Calculator | Day 23 – Veda Technology Internship

A responsive Tip Calculator built using HTML, CSS, and JavaScript. This project calculates the tip amount, total bill, and bill per person.

## ✨ Features

- Enter the bill amount
- Select a tip percentage (10%, 15%, or 20%)
- Enter a custom tip percentage
- Split the bill among multiple people
- Calculate the tip amount and total bill
- Display the amount payable per person
- Reset the calculator
- Validate user inputs
- Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the bill amount, select a tip percentage, and enter the number of people.
5. Click **Calculate Tip** to see the results.

## 🧮 Calculation Formula

- Tip Amount = Bill Amount × Tip Percentage ÷ 100
- Total Bill = Bill Amount + Tip Amount
- Per Person = Total Bill ÷ Number of People
